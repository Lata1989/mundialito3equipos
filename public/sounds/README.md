# 🎵 Carpeta de Sonidos

Coloca aquí tus archivos de audio en formato MP3:

- `pase-largo.mp3` - Sonido de pase largo (whoop/whoosh)
- `pase-corto.mp3` - Sonido de pase corto (bip/tap)
- `perdida.mp3` - Sonido de pérdida/fallo (error sound)
- `gol.mp3` - Sonido de gol (crowd cheer/whistle)

## Donde descargar

- **Freesound.org**: https://freesound.org/
- **Zapsplat**: https://www.zapsplat.com/
- **BBC Sound Effects**: https://sound-effects.bbcrewind.co.uk/

## Recomendaciones

- Formato: MP3
- Duración: 0.5 - 1.5 segundos
- Tamaño: < 200KB
- Calidad: 128kbps es suficiente

## Para convertir archivos

Si tienes archivos en otro formato:
- https://online-convert.com/
- FFmpeg: `ffmpeg -i archivo.wav archivo.mp3`
